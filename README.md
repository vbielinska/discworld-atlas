# Discworld Atlas

A fan-made guide to the Discworld universe created by Terry Pratchett.

## About the Project

Discworld Atlas is a web development project designed to introduce readers to the characters, books, places, and ideas of Terry Pratchett's Discworld series.

The goal is to create an atmospheric and accessible online encyclopedia for both new readers and longtime fans.

## Features

- **Books** — explore the Discworld novels and reading orders.
- **Characters** — discover important characters and their connections.
- **World & Places** — explore locations across the Discworld.
- **About Terry Pratchett** — learn about the author's life and work.

## Technologies

- HTML5
- CSS3
- Git and GitHub

Currently in development.
