# Discworld Atlas

An interactive-style encyclopedia and reading guide dedicated to the Discworld fantasy series by Terry Pratchett.

## About the Project

Discworld Atlas is a website designed to introduce new readers to the world of Discworld. It brings together information about the books, characters, and different storylines in one place, helping readers explore the series and find a starting point.

The project focuses on creating an atmospheric, accessible, and easy-to-navigate experience inspired by the magical and satirical world of Terry Pratchett.

## Features

- **Choose Your Guide** — discover the Discworld through characters such as Rincewind, Death, the Witches of Lancre, and Samuel Vimes.
- **Book Series** — explore different Discworld storylines and their books.
- **Reading Guide** — learn about the different series and possible reading orders.
- **Atmospheric Design** — explore a dark fantasy-inspired interface with a starry background, deep blue tones, and golden accents.
- **Responsive Layout** — a layout designed to adapt to different screen sizes.

## Technologies

- HTML5
- CSS3
- CSS Grid and Flexbox
- CSS Custom Properties
- Responsive Web Design
- Google Fonts

## Design

The visual concept is inspired by an astronomer's atlas: a mysterious night sky, deep blue backgrounds, warm golden accents, and classic serif typography.

The design uses reusable CSS variables for colours, spacing, typography, and layout to keep the styles consistent and maintainable.

## Project Goals

This project was created as part of my software development studies at Keuda. Its purpose is to practise and improve my skills in:

- Writing semantic and accessible HTML.
- Building responsive layouts with modern CSS.
- Organising styles using a maintainable CSS architecture.
- Creating consistent visual designs with reusable design tokens.
- Presenting information through clear navigation and structured content.

## Status

The project is a work in progress. More content and improvements may be added as development continues.
